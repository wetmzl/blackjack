# House of Chances

Android 竖屏优先的单机 PWA：黑杰克、累积式俄罗斯轮盘、技能卡，以及策展人与泰拉与会者之间的死亡对决。

玩家是来自高位面的“策展人”，向整个泰拉发出邀请。怀着执念的与会者进入古堡并参加“黑杰克轮盘赌”；策展人能够回溯自己落败的时间线，但与会者永远不会知道这一点。

## 本地运行

```bash
npm install
npm run dev
```

## 验证

```bash
npm test
npm run test:e2e
npm run build
```
