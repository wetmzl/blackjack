# 新增教程

教程是表现层的启发式提示：只有应用确认玩家已经遇到某项机制后，才派发对应 cue。教程不进入 `MatchState`、不参与 reducer，也不消耗领域随机数。

## 教程定义

教程统一维护在 `src/tutorials/tutorials.ts` 的 `TUTORIAL_DEFINITIONS`。每项定义包含：

- 稳定且唯一的 `id`；一经发布不要复用给不同教程。
- 用于触发的 `cue`。
- 一个或多个 `tags`，供 `completeTutorialsByTag` 批量完成同类教程。
- 非空 `pages`；页数没有上限，每页包含正文，并可带零个或多个图片资源。

页面资源目前使用 `{ type: "image", src, alt, caption? }`。图片须遵循现有资源路径与无障碍替代文本规范。

## 触发与完成

应用编排层必须从已经发生的领域状态变化或领域事件产生 cue，不能按时间、访问次数或猜测玩家接下来可能遇到的机制提前展示。恢复对局时，只能依据存档中仍然可观察到的机制事实补发未完成教程。技能抽卡教程只在 `OPEN_SKILL_DRAW` 已成为合法操作时触发，单独获得抽卡次数不会提前展示。

右上角教程弹窗是非模态界面。每页固定提供“跳过”和“下一步”；最后一页将“下一步”替换为“好的”。“跳过”与“好的”都会把当前教程 ID 写入长期存档。

每个新显示的教程弹窗默认在 10 秒后自动跳过，底部 2px 的无边框白灰渐变细条显示倒计时。计时结束后弹窗渐隐，完成渐隐才写入完成状态。玩家点击弹窗内除“跳过”之外的任意位置时，本次教程的自动跳过立即永久取消；渐隐期间仍可点击中断并恢复弹窗。翻页、切换场景或主动完成教程时必须同步清理计时器和渐隐动画。减少动态效果开启时仍保留 10 秒计时，但不播放持续进度动画，并将结束渐隐压缩为即时反馈。

## 存档兼容

长期档使用 `tutorialProgress.completedIds` 保存开放式字符串 ID。Schema 不枚举教程 ID；未知、删除或未来新增的教程 ID 都合法。旧档缺少 `tutorialProgress` 时按空集合读取，因此新增教程定义不需要提升长期存档版本，也不得使已有存档失效。
