# 美术管线

本轮与会者美术母版位于 `art/source/master-anime-style-sheet.png`。场景统一属于策展人的古堡；角色穿着策展人指定的参局服装。生产资源遵循以下确定性流程：

1. 以母版和用户提供的 W 参考图作为角色身份、色板、日式二次元画风、光照和 UI 语言参考。
2. 生成单一用途的源图，不让图像模型生成扑克牌数字、花色或规则文本。
3. 检查透明通道、角色身份、裁切和移动端可读性。
4. 只做受控裁切、缩放和格式优化；不堆叠不可复现滤镜。
5. 最终 Web 资源进入 `public/assets/`，牌面与状态图标优先由 DOM/CSS 程序化生成。

## 本轮 ImageGen 提示词组

- 角色母版：以参考角色的白发、红角、红黑指定服装和危险又玩味的气质为身份锚点，生成轻松、纠结、嘲笑、被瞄准和死亡等统一横向半身状态；简洁日式二次元游戏立绘，适合移动端牌桌分层，不生成文字。死亡态继续写入兼容性资源槽 `unconscious`。
- 思考状态：直接从 W 的轻松坐姿母版做身份保持编辑；保持完全相同的 3:2 横向半身裁切、坐姿重心和桌沿手臂位置，只把微笑收成专注的不满表情，并轻微收紧托腮手势，避免状态切换产生大幅动作跳变。
- 被瞄准状态：从标准轻松立绘做身份保持编辑；W 双手处于低位，头部微退、看向画面右侧，紧张咬牙并有汗珠，头部右侧为独立发牌员道具层留出空间；不生成枪、外部手或家具，最终交付真实透明通道。
- 死亡状态：从同一标准立绘做身份保持编辑；表现实弹击发后的生命终止，上身仅微微后仰、双眼失焦、双臂松弛，保持相同横向半身裁切；画面不表现血迹或开放性创伤，严格禁止椅子、桌子、床或其他支撑物，最终交付真实透明通道。
- 策展人胜利总结专用状态：独立竖版全身立绘；W 失去生命体征、四肢松弛地瘫坐在简洁工业金属椅上，从帽角到双靴和整张椅子均完整可见。椅子只允许出现在与会者死亡后的 Match Summary，不与牌桌死亡状态复用，最终交付真实透明通道。
- 收藏陈列专用状态：独立 16:4.5 超宽全身插画；W 的遗体仰面平躺在窄棺木式工业收纳舱中、四肢像被随手放入后一样自然摊开，保持红黑服装、白发和角饰一致；不生成场景背景、文字或扑克牌，舱体之外交付真实透明通道。
- 发牌员道具：独立、可复用的真实 7mm 六发左轮和发牌员手臂；深色钢制枪身、可信的枪管、弹巢、击锤、扳机护圈和木质握把，中性灰色技术手套、灰白制服袖口，枪口向左，使用真实透明通道。禁止玩具、水容器、红色安全帽和蒸汽朋克装饰。
- 背景：昏暗古堡中的封闭牌室，石砌拱顶、深色木墙、旧式吊灯和冷色陈列光，中央留出与会者与 UI 安全区，不生成角色和文字。

## 德克萨斯提示词组

- 身份母版：以用户提供的德克萨斯参考图作为身份锚点，保持深蓝黑长发、狼耳、琥珀眼、黑白蓝制服、长手套与克制沉稳的气质；简洁日式二次元游戏立绘，3:2 横向半身坐姿，真实透明通道，不生成武器、文字或背景。
- 轻松：坐在牌桌后，肩颈放松、神情中性，双前臂自然落在隐含桌沿；作为其他常规状态的身份、构图与光照母版，不画出椅子和桌子。
- 纠结：从轻松母版做身份保持编辑；一手托住下巴观察牌面，眉眼轻微收紧，不表现夸张焦虑。
- 嘲笑：从轻松母版做身份保持编辑；只有很淡的半笑和略微抬起的眉梢，不改变服装、体型和镜头。
- 被瞄准：从轻松母版做身份保持编辑；头部微退、视线看向画面右侧，嘴唇收紧并带少量汗珠，双手保持低位；不得生成枪、外部手或家具，为独立发牌员道具层留出头部空间。
- 牌桌死亡：表现实弹击发后的生命终止，双眼失焦、身体仅微微后仰、双臂自然松弛；不表现血迹或开放性创伤，严格禁止椅子、桌子、床或其他支撑物。
- 策展人胜利总结：独立竖版全身立绘；遗体四肢松弛地瘫坐在简洁工业椅上，角色、双靴和整张椅子完整可见；只用于与会者死亡后的 Match Summary。
- 收藏陈列：独立 16:4.5 超宽全身插画；遗体仰面平躺在窄棺木式工业收纳舱中，四肢自然松弛但姿态克制，完整保留深蓝黑长发、狼耳与黑白蓝指定服装；不生成场景背景和文字，舱体之外交付真实透明通道。W 与德克萨斯可以先在一张 16:9 图中上下各占一半生成，再精确裁切为两张 1600×450 资源。

德克萨斯沿用 W 的完整 `CharacterDefinition` 数据结构与共享发牌员道具，只单独配置角色资源、对白、AI 参数、牌桌显示缩放和头部瞄准点。她的 AI 理性程度更高、性格要牌倾向更低；视觉与对白也相应减少夸张动作。

与会者扳机状态始终由“被瞄准的紧张人物立绘”和“发牌员手持深色钢制 7mm 左轮”在 DOM 中分层合成；发牌员图层可跨角色复用，道具只朝向当前受罚与会者的头部，并通过代码完成抵近与回缩动画。策展人受罚时枪口朝向天花板，不能复用此头部瞄准构图。

被瞄准与死亡源图先做身份保持编辑，再做独立的精确抠图：删除整张背景和残留棋盘格，只保留角色及柔和边缘 alpha。若图像模型把棋盘格烘焙进 PNG，使用 `node tools/art/remove-checkerboard.mjs <输入> <输出>` 清除与画布边缘相连及封闭的大块中性棋盘格，同时保留角色内部的白发与高光。导入项目前必须用像素统计验证同时存在全透明、半透明和不透明像素，不能只凭预览中的棋盘格判断透明度。
